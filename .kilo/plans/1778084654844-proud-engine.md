# Plan: Modify Bottom Navigation in Love Shack v3

## Goal
Modify the bottom navigation in `v3/index.html` to have tabs for Home (dashboard), Source List, Clients List, Food Menu, and a hamburger menu that deploys the bottom sheet with menu items. The content for each tab loads in `id="app"` as screens. Use data from `reservations/data/` for the lists.

## Current State Analysis
- App in `v3/`, uses hash routing for screens (dashboard, step1, etc.).
- Bottom nav rendered by `bottom-nav.js`, only Home currently.
- Data: `reservations/data/menu-options.json` for sources/food, `loveshack_reservations.json` for clients.

## Proposed Changes
1. **Update Nav Structure:**
   - Replace or modify nav to have 4 tabs: Home, Source List, Clients List, Food Menu, and hamburger.
   - Use island nav from nav-bottom-bar for the behavior.

2. **Add Sheet for Hamburger:**
   - Sheet with menu-grid for additional options (share, reload, settings, profile, theme).

3. **Add New Screens:**
   - `source-list.js`, `clients-list.js`, `food-menu.js` in `js/screens/`.
   - Load data and display lists in `id="app"`.

4. **Update Routing:**
   - Add routes in `app.js` for #/source-list, #/clients-list, #/food-menu.

5. **Styling:**
   - Integrate nav-bottom-bar CSS into v3.

## Implementation Steps
1. **Read Files:**
   - nav-bottom-bar for nav structure.
   - app.js for routing.
   - Existing screens for pattern.

2. **Update v3/index.html:**
   - Add island nav with 4 buttons (links to hashes) and menu-trigger.
   - Add sheet HTML with menu-grid only.

3. **Create New Screens:**
   - source-list.js: Display reservationSources as list.

4. **Update app.js:**

5. **Test:**
