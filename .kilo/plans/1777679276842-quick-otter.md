# Plan: Align wheel-3d Behavior in v3 with Corrected pricing-calculator

## Problem
The wheel-3d picker in v3 has multiple discrepancies compared to the corrected `pricing-calculator` version:

1. **Manual keyboard input fails** — A separate event listener on `.input-trigger` interferes with the native input's focus/input behavior, preventing users from typing numbers directly.
2. **Wrong angular step** — v3 uses `stepAngle = 360/24 = 15°` while `pricing-calculator` uses a constant `STEP_ANGLE = 22°`. This makes the wheel spacing visually different and changes scroll feel.
3. **Missing keyboard shortcuts** — v3 lacks several keyboard interactions present in `pricing-calculator`: Enter-to-blur, number-key direct input, and Escape-to-close.
4. **Wheel-item data attribute naming** differs (`data-val` vs `data-wheel-value`) — doesn't affect functionality but breaks DOM parity.

## Solution
Match the working pattern from `pricing-calculator` exactly across all aspects.

### 4. `v3/js/screens/step1-pricing.js` — bindEvents() Global Keyboard

**Replace** the existing global `keydown` listener (lines ~236–262) with the full `pricing-calculator` version that includes:

- Escape → close picker
- **Number keys 0–9** → directly set value & sync wheel
- ArrowUp/ArrowDown → increment/decrement (already present)

New code:

```javascript
document.addEventListener('keydown', (e) => {
  const isOpen = document.getElementById('bottomSheet')?.getAttribute('data-open') === 'true';
  if (!isOpen) return;

  // Escape closes the sheet
  if (e.key === 'Escape') {
    this.closePicker();
    return;
  }

  const conf = this.picker.config[this.picker.mode];
  const summaryEl = document.getElementById(`summary${this.capitalize(this.picker.mode)}`);

  // Number keys 0-9: direct value input
  if (e.key >= '0' && e.key <= '9') {
    const val = parseInt(e.key);
    if (val >= conf.min && val <= conf.max) {
      summaryEl.textContent = val;
      this.syncPickerToValue(val);
      this.recalculate();
      // Optional haptic
      if (navigator.vibrate) navigator.vibrate(15);
    }
    return;
  }

  // Arrow keys: increment/decrement
  const currentVal = parseInt(summaryEl.textContent) || conf.min;
  let newVal = currentVal;

  if (e.key === 'ArrowUp') {
    e.preventDefault();
    newVal = Math.min(currentVal + 1, conf.max);
  } else if (e.key === 'ArrowDown') {
    e.preventDefault();
    newVal = Math.max(currentVal - 1, conf.min);
  }

  if (newVal !== currentVal) {
    summaryEl.textContent = newVal;
    this.syncPickerToValue(newVal);
    this.recalculate();
  }
});
```

### 7. Haptic Feedback (Optional)

If you want haptic feedback on scroll (like `pricing-calculator`), add inside `bindEvents()` after the scroll listener:

```javascript
let lastIdx = -1;
scrollWrapper?.addEventListener('scroll', () => {
  if (this.picker.isSyncing) return;
  const progress = scrollWrapper.scrollTop / this.picker.itemHeight;
  const activeIndex = Math.round(progress);
  const conf = this.picker.config[this.picker.mode];
  const val = activeIndex + conf.min;

  this.updateWheelRotation(progress);
  this.updateActiveClasses(val);
  
  if (val >= conf.min && val <= conf.max) {
    document.getElementById(`summary${this.capitalize(this.picker.mode)}`).textContent = val;
    this.recalculate();
  }

  // Haptic on index change
  if (activeIndex !== lastIdx && activeIndex >= 0 && activeIndex <= conf.max - conf.min) {
    if (navigator.vibrate) navigator.vibrate(8);
    lastIdx = activeIndex;
  }
});
```

## Why These Changes Work

- **Inline `onclick`** avoids event listener interference that broke input focus.
- **`focus` handler** initializes typing state cleanly.
- **`keypress` Enter** provides a natural commit action.
- **Global number keys** let users tap digits directly without touching the input (a key UX feature).
- **Arrow keys** continue working as before.
- **`stepAngle = 22`** aligns the visual wheel curvature exactly.
- **Haptic** adds tactile polish on supported devices.
